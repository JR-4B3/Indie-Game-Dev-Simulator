# JetBrains Mono

Regular, SemiBold and Bold WOFF2 files from JetBrains Mono **v2.304**:

https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts

Copyright and redistribution terms are included in `OFL.txt` (SIL Open Font
License 1.1). Files are unmodified. The browser loads these files from the
local server; no CDN, system font installation, or internet access is needed.

The development machine's `ghostty +show-face --string='Studio 0123'`
reports **JetBrains Mono**. This matches the typeface, not a guarantee of
identical terminal/browser antialiasing or identical font-version metrics.
